AI 读书笔记网站案例

案例背景

个人知识管理需求日益增长，用户希望通过 AI 辅助快速提取、总结和可视化阅读内容。

任务书澄清

设计一个支持多格式导入、AI 摘要、语义搜索和知识图谱可视化的读书笔记平台。

必达要求 / 愿望

  • 必达：PDF/EPUB/Markdown 导入、AI 摘要准确率 > 85%、语义搜索 < 300ms
  • 愿望：多用户协作、多种格式导出、优秀移动端体验

功能分解

总功能：知识管理 → 分功能：导入、AI处理、检索、可视化、导出。

方案变型

考虑 RAG 架构、本地 LLM、图数据库、静态站点生成等方案变型。

评价准则

准确性、隐私性、性能、可维护性、成本。

推荐路线

本地优先 + RAG + 静态生成 + Hermes Agent 辅助。

可复用模板

任务书澄清模板、功能分解模板、方案评价矩阵。

可交给 Agent 的下一步命令示例

请使用任务书澄清模板，帮我把“AI 读书笔记网站”需求转化为结构化任务书。
