Agent 工作流

工程设计方法论可直接映射为 Hermes Agent 的结构化工作流。

从想法到任务书

输入：原始想法
步骤：收集需求 → 明确利益相关者 → 撰写初稿 → 多轮澄清
输出：结构化任务书
失败风险：需求模糊
人类复核点：必达要求确认

从任务书到功能结构

输入：任务书
步骤：提取总功能 → 分解分功能 → 建立结构 → 定义输入输出
输出：功能结构图
失败风险：分解过细或遗漏
人类复核点：功能完整性

从功能结构到作用原理

输入：功能结构
步骤：搜索原理 → 评估可行性 → 生成变型
输出：原理列表
失败风险：原理不匹配
人类复核点：可行性判断

从作用原理到方案矩阵

输入：原理
步骤：组合变型 → 建立准则 → 填充矩阵 → 筛选
输出：推荐方案
失败风险：评价主观
人类复核点：最终选择

从方案到技术设计检查

输入：推荐方案
步骤：参数计算 → 结构设计 → 工艺规划 → 检查
输出：技术设计文件
失败风险：参数不合理
人类复核点：安全与可制造性

从技术设计到施工文件

输入：技术设计
步骤：绘制图纸 → 零件表 → 工艺文件 → 检查
输出：完整施工文件包
失败风险：文件不一致
人类复核点：完整性审查

命令示例（可直接复制给本地 Hermes）

1. 把一个想法转成任务书
请使用任务书澄清模板，把“AI 读书笔记网站”需求转化为结构化任务书。

2. 把任务书转成功能结构
请使用功能分解模板，对已澄清的任务书进行功能结构分解。

3. 把三个方案转成评价矩阵
请使用方案评价模板，对三个候选方案进行多维度评价并输出矩阵。
