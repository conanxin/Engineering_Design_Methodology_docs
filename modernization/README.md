# Engineering Design Methodology — Modernization Notes

## 项目目标

本 modernization 目录旨在将原 Sphinx + reStructuredText 工程设计方法学笔记整理为现代化的 GitHub Pages 静态专题页面。

具体方向：
- 保留原始 .rst 文件作为 source_archive/ 只读归档
- 新建 site/ 目录生成可直接发布的静态 HTML 原型
- 建立 data/ 下的结构化 JSON（concepts、checklists、workflows）
- 为后续 Hermes Agent / OpenClaw skill 化提供可复用模板与数据接口
- 避免直接大段复制原文，优先使用摘要、重写、导航与个人方法论解释

## 版权边界声明

- 原始内容来源于早期读书笔记与学习记录
- 新页面以“方法论重写、结构化摘要、流程导航、模板化输出”为主
- 禁止大段原文搬运，降低版权风险
- 所有新内容均为原创性总结与重新组织
