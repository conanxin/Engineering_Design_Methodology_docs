一个完整使用流程

  1. 写下项目想法
  2. 用任务书模板澄清必达要求与愿望
  3. 建立功能结构
  4. 生成 3 个方案并形成矩阵
  5. 评价方案并选择推荐路线
  6. 输出技术设计检查清单
  7. 进入实施或 Agent 执行

最小可用工作流（6 步）

1. 写下项目想法
2. 用任务书模板澄清
3. 用功能分解模板拆解
4. 生成 3 个方案
5. 用评价矩阵比较
6. 输出下一步执行命令
