# engineering-design-methodology-skill

**注意**：这是 Phase 1C 草案，仅用于演示与研究，不得直接安装到 ~/.hermes/skills。

## 用途
- 任务书澄清
- 功能分解
- 方案生成与评价
- 技术设计检查
- 成本估算
- Agent 工作流模板输出

## 输入/输出格式
输入：自然语言需求或任务书片段  
输出：结构化 Markdown / JSON（含必达要求、功能结构、评价矩阵等）

## 版权边界
本 skill 仅使用工程设计方法论框架与原创转译，不复述原书长段落。

## 调用示例
1. 任务书澄清
2. 功能分解
3. 方案评价
4. 技术设计审查
5. 成本估算模板生成

## 安全边界
- 所有工程方案必须人工复核
- 不替代注册工程师或安全审查
- 涉及施工、机械、电气安全时必须由专业人员审查
