GitHub Pages 互动专题页案例

案例背景

将传统工程设计方法论整理为现代可交互的 GitHub Pages 专题。

任务书澄清

设计支持章节导航、案例演示、SVG 图解和 Agent 工作流入口的静态专题页。

必达要求 / 愿望

必达：纯静态可部署、移动端友好、无外部依赖。愿望：支持搜索、导出 PDF。

功能分解

总功能：知识展示 → 分功能：导航、内容渲染、交互、Agent 入口。

方案变型

纯 HTML/CSS/JS、MkDocs、Astro、自定义生成。

评价准则

加载速度、可访问性、维护成本、扩展性。

推荐路线

纯静态 HTML + SVG + JSON 数据驱动。

可复用模板

章节页面模板、案例页面模板。

可交给 Agent 的下一步命令示例

请生成一个支持章节导航的 GitHub Pages 专题页结构。

Phase 1C 案例页面：用于方法论演示，非正式工程交付文件。
