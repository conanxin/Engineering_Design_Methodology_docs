本地 Agent 工具链案例

案例背景

扩展 Hermes Agent 支持工程设计方法论的完整工作流。

任务书澄清

设计一套可本地运行的 Agent 工具链，支持任务澄清、功能分解、方案评价和技术检查。

必达要求 / 愿望

必达：完全本地运行、支持多模型切换、输出结构化 JSON。愿望：支持语音输入、多项目记忆。

功能分解

总功能：工程设计辅助 → 分功能：需求解析、方案生成、评价、输出模板。

方案变型

本地 LLM、RAG 知识库、结构化输出、多 Agent 协作。

评价准则

准确性、隐私、速度、可扩展性。

推荐路线

Hermes + 本地模型 + 结构化输出 + skill 框架。

可复用模板

所有工程设计模板。

可交给 Agent 的下一步命令示例

请使用工程设计方法论，把一个想法转成功能结构。

Phase 1C 案例页面：用于方法论演示，非正式工程交付文件。
